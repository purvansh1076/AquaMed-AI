# Human-Supervised Pilot Workflow

## Workflow

1. Authorized user creates scenario.
2. System validates inputs.
3. Agronomic demand calculated.
4. ML prediction + uncertainty.
5. Agents propose.
6. LP allocation.
7. Constraint verification.
8. Explainable recommendation.
9. Human review approve/reject/recalculate.
10. Decision recorded with audit trail.

No automatic physical distribution. Recommendations distinguished from actual allocation.
