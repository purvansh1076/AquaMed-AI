# Phase H Pilot Acceptance Criteria

## Engineering

- Reproducible staging, tests pass, no unresolved critical security defect, no invalid allocation, DB recovery tested, monitoring available, human approval enforced.

## Scientific

- Documented reference data, unit consistency, independent ET0 validation, crop-specific assessment, regional applicability assessment, known uncertainty.

## Go/No-Go

Pilot cannot be approved if critical safety defects, bypassable approval, unverifiable constraints, missing consent, unknown provenance, concealed limitations, or inadequate recovery.
