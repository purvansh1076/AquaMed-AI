# Phase H Pilot Evaluation Plan

## Metrics

Engineering: uptime, error rates, latency, failed scenarios, DB availability, ML/solver failures.
ML: prediction errors, bias, subgroup performance, interval coverage/width, drift.
Agronomy: predicted vs measured demand, ET0 comparison, crop/regional error.
Optimization: allocated/delivered water, satisfaction, unmet demand, Jain's index, violations.
Human review: approved/rejected/recalculation, reasons, time to decision, overrides.

## Methodology

Baseline, observation period, evaluation frequency, minimum sample size rationale, data-quality requirements, statistical methodology, reporting schedule, stop conditions.
